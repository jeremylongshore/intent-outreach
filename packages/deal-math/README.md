# @intent-outreach/deal-math

Pure real estate deal math for Intent Outreach packs. zod is the only dependency: no I/O, no clock, no
model. A pack runs it after scoring and hands the results to the draft step as computed facts, so the
LLM never does arithmetic.

## Conventions

- **Money is integer cents.** Rates are integer **basis points** (6.75% = 675). Ratios such as DSCR are
  basis points of 1.0 (1.25x = 12,500).
- **Rounding is half-even** (Python's `round()`), so figures ported from coastal-realty-ops match to the cent.
- **Assumptions are explicit.** A function that depends on a rate or a convention takes an `assumptions`
  object. There are no hidden defaults; named constants such as `COASTAL_TRADE_UP_ASSUMPTIONS` are passed
  in on purpose.
- **Every function returns `{ value, inputs, assumptionsUsed, version }`**, frozen, so a cited figure can
  be traced and reproduced.

## Functions

| Function | Value |
|---|---|
| `noi(inputs, {vacancyBps})` | effective gross income, vacancy loss, NOI (cents) |
| `capRate`, `dscr`, `cashOnCash` | basis points |
| `monthlyPayment` | level P&I payment (cents) |
| `sellerFinance(inputs, {annualRateBps, amortizationMonths, balloonMonth?})` | payment, total interest, balloon, optional schedule |
| `exchange1031Timeline` | 45-day identification and 180-day / return-due-date exchange deadlines; **informational only** |
| `tradeUp(inputs, assumptions)` | the condo → new-construction trade-up model, ported from coastal `trade_up.py` |

`tradeUp` parity is pinned by `tests/fixtures/deal-math/trade-up.golden.json`, generated by running
coastal's Python calculator. Regenerate it from that repo if the Python model changes, never by hand.
