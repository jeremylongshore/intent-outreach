# Support

- **Bugs and feature requests:** open a GitHub issue on `jeremylongshore/intent-outreach`, or email
  `jeremy@intentsolutions.io`.
- **Security issues:** follow `SECURITY.md` (email `security@intentsolutions.io`) — do not post publicly.
- **Commercial / enterprise licensing:** `jeremy@intentsolutions.io` · <https://intentsolutions.io>

Before reaching out, check `README.md` (setup + keys) and `CLAUDE.md` (architecture). Most "it didn't run"
issues are an unset provider key — `node bundle/cli.mjs connectors` shows which connectors are configured
and `node bundle/cli.mjs providers` shows which model providers are.
